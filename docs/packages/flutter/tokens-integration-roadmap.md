# 🔄 Roadmap: Integração de Tokens React ↔ Flutter

Este documento descreve o plano para sincronizar os design tokens entre React e Flutter.

## 📋 Situação Atual

### ✅ Tokens React (Style Dictionary)
- **Localização:** `packages/tokens/src/`
- **Formato:** JSON
- **Output:** CSS, SCSS, JS
- **Ferramenta:** Style Dictionary

### ✅ Tokens Flutter (Manual)
- **Localização:** `packages/components-flutter/lib/tokens/`
- **Formato:** Dart files
- **Manutenção:** Manual
- **Status:** Valores temporários/mockados

## 🎯 Objetivo

Automatizar a geração de tokens Flutter a partir dos tokens React usando Style Dictionary, garantindo sincronização automática.

## 📝 Plano de Implementação

### Fase 1: Configuração do Style Dictionary para Flutter

#### 1.1 Adicionar Formato Flutter ao Style Dictionary

**Arquivo:** `packages/tokens/config/style-dictionary.config.js`

```javascript
// Adicionar formato Dart
StyleDictionary.registerFormat({
  name: 'flutter/tokens',
  formatter: function(dictionary) {
    return `import 'package:flutter/material.dart';

/// Design tokens gerados automaticamente
/// Não edite manualmente - será sobrescrito!
class ZanthusColors {
  ZanthusColors._();

${dictionary.allProperties.map(prop => {
  if (prop.attributes.category === 'color') {
    return `  static const Color ${prop.name} = Color(${prop.value});`;
  }
}).filter(Boolean).join('\n')}
}`;
  }
});
```

#### 1.2 Adicionar Plataforma Flutter

```javascript
module.exports = {
  // ... configurações existentes
  
  // Nova plataforma Flutter
  flutter: {
    transformGroup: 'flutter',
    buildPath: '../components-flutter/lib/tokens/generated/',
    files: [
      {
        destination: 'colors.dart',
        format: 'flutter/tokens',
        filter: { attributes: { category: 'color' } }
      },
      {
        destination: 'spacing.dart',
        format: 'flutter/spacing',
        filter: { attributes: { category: 'spacing' } }
      },
      {
        destination: 'typography.dart',
        format: 'flutter/typography',
        filter: { attributes: { category: 'typography' } }
      }
    ]
  }
};
```

### Fase 2: Transformers Customizados

#### 2.1 Transformer de Cores

Converter cores CSS para Flutter Color:

```javascript
StyleDictionary.registerTransform({
  name: 'color/flutter',
  type: 'value',
  matcher: token => token.attributes.category === 'color',
  transformer: token => {
    // #RRGGBB -> 0xFFRRGGBB
    const hex = token.value.replace('#', '');
    return `0xFF${hex}`;
  }
});
```

#### 2.2 Transformer de Spacing

Converter pixels para double:

```javascript
StyleDictionary.registerTransform({
  name: 'size/flutter',
  type: 'value',
  matcher: token => token.attributes.category === 'spacing',
  transformer: token => {
    // "16px" -> 16.0
    return parseFloat(token.value);
  }
});
```

#### 2.3 Transformer de Typography

```javascript
StyleDictionary.registerTransform({
  name: 'typography/flutter',
  type: 'value',
  matcher: token => token.attributes.category === 'typography',
  transformer: token => {
    // Mapear pesos de fonte
    const fontWeightMap = {
      400: 'FontWeight.w400',
      500: 'FontWeight.w500',
      600: 'FontWeight.w600',
      700: 'FontWeight.w700'
    };
    return fontWeightMap[token.value] || token.value;
  }
});
```

### Fase 5: Scripts de Build

#### 5.1 Atualizar package.json

```json
{
  "scripts": {
    "build:tokens": "style-dictionary build",
    "build:tokens:flutter": "style-dictionary build --platform flutter",
    "build:tokens:all": "style-dictionary build --platform css,scss,js,flutter",
    "watch:tokens": "nodemon --watch src --exec 'pnpm run build:tokens:all'"
  }
}
```

#### 5.2 Criar Script de Sincronização

**Arquivo:** `scripts/sync-flutter-tokens.sh`

```bash
#!/bin/bash

echo "🔄 Sincronizando tokens para Flutter..."

# Build tokens
cd packages/tokens
pnpm run build:tokens:flutter

# Copiar para Flutter
cp build/flutter/*.dart ../components-flutter/lib/tokens/generated/

# Formatar código Dart
cd ../components-flutter
flutter format lib/tokens/generated/

echo "✅ Tokens sincronizados com sucesso!"
```

### Fase 6: CI/CD

#### 6.1 GitHub Actions

```yaml
name: Sync Tokens

on:
  push:
    paths:
      - 'packages/tokens/src/**'

jobs:
  sync-tokens:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      
      - name: Setup Node
        uses: actions/setup-node@v3
        
      - name: Setup Flutter
        uses: subosito/flutter-action@v2
      
      - name: Install dependencies
        run: pnpm install
      
      - name: Build tokens
        run: |
          cd packages/tokens
          pnpm run build:tokens:all
      
      - name: Sync Flutter tokens
        run: ./scripts/sync-flutter-tokens.sh
      
      - name: Create PR
        uses: peter-evans/create-pull-request@v5
        with:
          commit-message: 'chore: sync Flutter tokens'
          title: 'chore: Auto-sync Flutter tokens'
```
