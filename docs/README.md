## 💡 Dicas Rápidas

### Comandos Mais Usados

```bash
# Executar Widgetbook
cd apps/widgetbook-flutter && flutter run -d chrome

# Instalar dependências
flutter pub get

# Análise de código
flutter analyze

# Testes
flutter test

# Formatar código
flutter format .
```

### Atalhos do VS Code

- `F5` - Iniciar debugging
- `Ctrl+Shift+P` → `Flutter: Hot Reload` - Hot reload
- `Ctrl+Shift+P` → `Flutter: New Widget` - Criar widget
- `Ctrl+.` - Quick fixes

### Durante Execução

- `r` - Hot reload
- `R` - Hot restart
- `q` - Quit
- `h` - Help
