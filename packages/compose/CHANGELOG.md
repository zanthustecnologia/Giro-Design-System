# Changelog

All notable changes to the Zanthus Compose Components package.

## [0.1.0] - 2025-12-12

### Added
- Initial release of Zanthus Compose components
- **56+ Material 3 Pure Components** (re-exports nativos):
  - Actions (13): Buttons (5 variants), FAB (4 variants), IconButton (4 variants)
  - Communication (4): AlertDialog, Snackbar, ProgressIndicator (2 variants)
  - Containment (4): Card (3 variants), Divider
  - Navigation (14): TopAppBar (4 variants), BottomAppBar, NavigationBar, NavigationRail, NavigationDrawer (3 variants), Tabs (3 components)
  - Selection (15): Checkbox, Switch, RadioButton, Slider (2 variants), Chips (7 variants)
  - Input (2): TextField, OutlinedTextField
  - Data Display (3): ListItem, Badge, Tooltip
  - Layout (1): Scaffold
- Type aliases for cleaner API usage
- Complete documentation with usage examples
- Material 3 Compose support (BOM 2024.01.00)

### Notes
- All components are pure re-exports from androidx.compose.material3
- Follows 100% the official Material Design 3 specification
- Compatible with Jetpack Compose 1.5+
- Minimum SDK: Android 24 (Android 7.0)
- Target SDK: Android 34
