# @zanthus/icons

Este pacote encapsula **todos os ícones do Fluent UI React** dentro do design system da Zanthus, permitindo uso simplificado e controlado via componente `<Icon />`.

---

## 🚀 Instalação

```bash
npm install @zanthus/icons
```

> Este pacote depende de `@fluentui/react-icons`.

---

## 📦 Como usar

```jsx
import { Icon } from "@zanthus/icons";

<Icon name="Add24Regular" />
```

---

## ✅ Vantagens

- Acesso total à biblioteca Fluent
- Componente semântico e reutilizável
- Encapsulamento da dependência externa
- Suporte a autocomplete e tree-shaking
