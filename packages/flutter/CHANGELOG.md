# Changelog

All notable changes to the Zanthus Flutter Components package will be documented in this file.

## [0.4.0] - 2026-06-02

### Features

- **Button:** novo componente com design visual oficial do Flutter-Giro
- **Chip:** novo componente customizado
- **Tokens:** novos design tokens para expandir integração com o Design System

## [0.3.0] - 2025-12-12

### Breaking Changes

- **Pacote:** remove todos os componentes customizados com wrappers; pacote passa a conter apenas re-exports de componentes Material 3 puros

### Features

- **Componentes:** adiciona 18 novos componentes Material 3 (Buttons, IconButton, TextField, ListTile, Dialogs, PopupMenuButton, Dropdown, Checkbox, Switch, Radio, Card, Chips, Badge, CircleAvatar, Tooltip, Divider, Form, Scaffold, ButtonBar, RefreshIndicator)

### Removed

- Todos os componentes customizados anteriores

## [0.2.0] - 2025-12-12

### Features

- **Componentes:** adiciona 21 componentes Material 3 puros (FAB, SegmentedButton, SnackBar, BottomSheet, Drawer, AppBar, NavigationBar, Slider, DatePicker, Menu, Autocomplete, DataTable, Stepper, ExpansionPanel, entre outros)

## [0.1.0] - 2025-12-12

### Features

- **Release Inicial:** design tokens (cores, spacing, tipografia, border-radius, shadows) e componentes base (Avatar, Badge, Button, Card, Checkbox, Chip, Dialog, Divider, Dropdown, Input, List Item, Radio, Select, Switch, Text, Tooltip)
