# TextArea

TextArea é um campo de entrada de texto multilinha que permite ao usuário inserir textos longos, como descrições, comentários ou observações.

<Canvas of={TextAreaStories.Default} />

## Importação

```js
import { TextArea } from '@giro-ds/react';
```

## Propriedades

<Controls />

## Uso

<UsageGuidelines
  guidelines={[
    <>
      Use TextArea para entrada de textos longos, como descrições, comentários e observações.
    </>,
    <>
      Defina sempre um <code>label</code> descritivo para identificar claramente o campo.
    </>,
    <>
      Utilize <code>helperText</code> para orientar o usuário sobre o que deve ser inserido no campo.
    </>,
    <>
      Combine <code>maxLength</code> com <code>showCharCount</code> para exibir o contador de caracteres restantes.
    </>,
    <>
      Prefira <code>resize="vertical"</code> (padrão) ou <code>resize="none"</code> para evitar quebras de layout.
    </>,
  ]}
/>

## O que fazer e não fazer

<ComponentRules
  rules={[
    {
      positive: {
        component: <TextArea label="Descrição" placeholder="Descreva brevemente..." helperText="Máximo 200 caracteres" maxLength={200} />,
        description: "Use label e helperText para guiar o usuário sobre o que deve ser preenchido."
      },
      negative: {
        component: <TextArea placeholder="Digite aqui..." />,
        description: "Evite deixar o campo sem label ou orientação. O usuário pode não entender o que inserir."
      }
    },
    {
      positive: {
        component: <TextArea label="Comentário" resize="vertical" />,
        description: "Permita redimensionamento vertical para que o usuário ajuste o campo ao seu conteúdo."
      },
      negative: {
        component: <TextArea label="Comentário" resize="both" />,
        description: "Evite resize horizontal, pois pode causar quebra de layout na página."
      }
    }
  ]}
/>
