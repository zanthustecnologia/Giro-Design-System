# Button

Botões são componentes interativos que acionam uma função, navegação ou mudança de estado na interface. 
Eles indicam ações principais e secundárias, ajudando usuários a decidir “o que fazer em seguida”.

<Canvas of={ButtonStories.Default} />

```js
import { Button } from '@giro-ds/react';
```

## Uso

<UsageGuidelines
  guidelines={[
    <>
      Botões podem conter ícones à esquerda ou à direita.
    </>,
    <>
      A largura do botão é definida pelo seu contéudo. Evite alterar a largura do botão.
    </>,
    <>
      Para casos onde o botão deve ocupar a linha inteira (ex.: mobile), use <code>fullWidth</code>.
    </>,
    <>
      Mantenha espaçamento horizontal mínimo de 16px entre botões.
    </>,
    <>
      Dentro de um mesmo contexto visual (card, seção, modal, página de fluxo), mantenha somente um botão primário.
    </>,
    
  ]}

## O que fazer e não fazer
<ComponentRules
  rules={[
    {
      negative: {
        component: [<Button>Adicionar usuários</Button>, <Button>Configurações</Button>],
        description: "Evite usar duas ações primárias no mesmo fluxo. Isso demonstra falta de foco e pode sobrecarregar os usuários."
      },
      positive: {
        component: [<Button>Adicionar usuários</Button>, <Button variant="outlined">Configurações</Button>],
        description: "Combine versões dos botões baseadas na hierarquia de acordo com o contexto da jornada."
      }
    },
    {
      negative: {
        component: [<Button>Começar Agora</Button>, <Button>COMEÇAR AGORA</Button>],
        description: "Para textos compostos, evite usar todas as letras maiúsculas ou iniciais maiúsculas."
      },
      positive: {
        component: <Button>Começar agora</Button>,
        description: "Use sempre apenas a primeira letra minúscula."
      }
    },
    {
      negative: {
        component: [<Button variant="text">Sim</Button>, <Button>Não</Button>],
        description: "Evite rótulos vagos e genéricos que forçam o usuário a ler o diálogo antes de agir."
      },
      positive: {
        component: [<Button variant="text">Cancelar</Button>, <Button>Começar agora</Button>],
        description: "Use verbos ativos ou frases que indiquem claramente a ação."
      }
    },
    {
      negative: {
        component: <Button>Clique para começar agora!</Button>,
        description: "Evite usar frases longas e pontuação final, como pontos finais ou de exclamação."
      },
      positive: {
        component: <Button>Começar agora</Button>,
        description: "Utilize uma ou duas palavras que indiquem claramente a ação sem pontuação final."
      }    },
    {
      negative: {
        component: [<Button icon={<Settings16Regular />}>Adicionar usuários</Button>, <Button variant="outlined">Configurações</Button>],
        description: "Não utilize ícones que não tenham um significado claro para o usuário"
      },
      positive: {
        component: [<Button icon={<Add16Regular />} iconPosition="left">Button</Button>, <Button variant="outlined" iconOnly icon={<Settings16Regular />} ariaLabel="Configurações" tooltipText="Configurações" />],
        description: "Botões podem ser utilizados apenas com ícones"
      }    }
  ]}
