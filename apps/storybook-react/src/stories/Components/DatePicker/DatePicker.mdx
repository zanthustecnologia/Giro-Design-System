# Date Picker

O Date Picker é um componente de entrada de data que combina um campo de texto com máscara e um calendário interativo. 
Permite que o usuário selecione uma data digitando diretamente ou navegando pelo calendário.

<Canvas of={DatePickerStories.Default} />

## Importação

```js
import { DatePicker } from '@giro-ds/react';
```

<Controls />

## Uso

<UsageGuidelines
  guidelines={[
    <>
      Sempre forneça um <code>label</code> descritivo para identificar o campo de data no contexto do formulário.
    </>,
    <>
      Use <code>helperText</code> para indicar o formato esperado ou dar instruções adicionais ao usuário.
    </>,
    <>
      Em formulários controlados, utilize as props <code>value</code> e <code>onChange</code> em conjunto para manter o estado sincronizado.
    </>,
    <>
      Use <code>minDate</code> e <code>maxDate</code> para restringir o intervalo de seleção quando a regra de negócio exigir.
    </>,
    <>
      O campo aceita entrada via teclado com máscara automática — o usuário não precisa digitar separadores como <code>/</code>.
    </>,
  ]}
/>

## O que fazer e não fazer

<ComponentRules
  rules={[
    {
      negative: {
        component: <DatePicker label="Data" />,
        description: "Evite usar o campo sem uma label descritiva, pois o usuário não saberá qual data é esperada."
      },
      positive: {
        component: <DatePicker label="Data de nascimento" helperText="Selecione sua data de nascimento" />,
        description: "Forneça sempre uma label clara e, quando necessário, um texto de ajuda com mais contexto."
      }
    },
    {
      negative: {
        component: <DatePicker label="Data de início" locale="pt-br" minDate={new Date(2100, 0, 1)} />,
        description: "Evite definir restrições de data que impossibilitem qualquer seleção válida no contexto do usuário."
      },
      positive: {
        component: <DatePicker label="Data de início" locale="pt-br" minDate={new Date()} />,
        description: "Use <code>minDate</code> e <code>maxDate</code> com valores coerentes ao fluxo, como impedir datas passadas em agendamentos futuros."
      }
    },
  ]}
/>
