# Toast

O Toast exibe notificações transitórias no canto inferior esquerdo da tela. É acionado de forma programática via hook e se fecha automaticamente após alguns segundos, sem interromper o fluxo do usuário.

<Canvas of={ToastStories.Tipos} />

## Configuração

O Toast requer dois componentes de infraestrutura adicionados uma única vez no nível da aplicação.

```jsx
import { ToastProvider, ToastContainer } from '@giro-ds/react';

function App() {
  return (
    <ToastProvider>
      {/* conteúdo da aplicação */}
      <ToastContainer />
    </ToastProvider>
  );
}
```

Para exibir um toast em qualquer componente filho:

```jsx
import { useToast } from '@giro-ds/react';

function MeuComponente() {
  const { showToast } = useToast();

  return (
    <Button onClick={() => showToast({ title: 'Dados salvos com sucesso.', iconType: 'Success' })}>
      Salvar
    </Button>
  );
}
```

## Uso

<UsageGuidelines
  guidelines={[
    <>
      Use o Toast para feedback transitório de ações do sistema, como confirmações de envio, exclusões ou erros leves. Não o use para comunicar erros críticos que exijam ação imediata do usuário.
    </>,
    <>
      Escolha o tipo de ícone de acordo com o contexto: <strong>Success</strong> para ações concluídas, <strong>Alert</strong> para avisos que merecem atenção mas não impedem o fluxo, e <strong>Info</strong> para notificações neutras.
    </>,
    <>
      Mantenha o título curto e objetivo. O Toast foi projetado para mensagens diretas: uma frase é o suficiente. Evite explicações longas.
    </>,
    <>
      Desative o fechamento automático apenas quando a informação contiver algo que o usuário precise ler com atenção antes de prosseguir, como um código ou aviso importante.
    </>,
    <>
      O sistema suporta até 5 toasts simultâneos. Quando esse limite é atingido, o mais antigo é removido automaticamente. Evite acionar múltiplas notificações em sequência rápida.
    </>,
    <>
      O Toast não substitui validações de formulário nem mensagens de erro inline. Use-o para feedback de ações globais, não para orientar o preenchimento de campos.
    </>,

## Variações

### Tipos de notificação

O Toast suporta três tipos visuais: informativo, sucesso e alerta. Cada tipo tem uma cor de ícone distinta que comunica a natureza da mensagem antes mesmo da leitura.

<Canvas of={ToastStories.Tipos} />

### Persistente

Quando `automaticClose` é desativado, o toast permanece visível até que o usuário o feche manualmente. Use apenas quando a informação precisar ser lida com atenção antes de prosseguir.
