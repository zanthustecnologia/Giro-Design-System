# Virtual Keyboard

O Virtual Keyboard é um teclado on-screen para ambientes onde o teclado físico está indisponível ou não é desejável — como totens, terminais e caixas de pagamento. Ele se integra a campos de texto controlados e suporta layouts nativos (padrão e numérico), além de layouts de idioma.

## Importação

```js
import { VirtualKeyboard } from '@giro-ds/react';
```

## Uso

<UsageGuidelines
  guidelines={[
    <>
      Sempre vincule o teclado a um campo de texto via <code>value</code> e <code>onChange</code>. O teclado é um componente controlado e não gerencia o estado do input por conta própria.

## Modos

O VirtualKeyboard possui dois modos de exibição, configurados pela prop `variant`.

### Fixed

O teclado fica sempre visível na tela com um **TextField próprio** acima. O campo é somente leitura — toda a entrada vem pelas teclas do teclado. Ideal para totens, painéis e interfaces sem teclado físico onde a digitação é o fluxo principal.

Use `textFieldLabel` e `textFieldPlaceholder` para personalizar o campo interno.

<Canvas of={VirtualKeyboardStories.ModoFixed} />

### Native

O teclado age como um teclado nativo: aparece quando o campo referenciado por `targetRef` recebe foco e some ao perder o foco (com um debounce de 150ms para não fechar antes do clique na tecla ser processado). Se `targetRef` não for fornecido, o teclado permanece sempre visível.

## Shift e CapsLock

O comportamento esperado das teclas de caixa alta e:

- Shift: altera para maiusculas somente na proxima tecla digitada e retorna para o layout default.
- CapsLock: alterna o modo caps de forma persistente e permanece ativo ate retornar para o layout default.

## Variações

### Numérico

Indicado para entradas de PINs, senhas e códigos. Exibe apenas os dígitos de 0 a 9, além de backspace e enter.

<Canvas of={VirtualKeyboardStories.Numerico} />

### Sem botao de smileys

Quando a tela nao deve permitir emojis, desative o botao de smileys com <code>showEmoticonButton=false</code>.

## O que fazer e não fazer

<ComponentRules
  rules={[
    {
      positive: {

      negative: {

        description: 'Evite omitir maxLength quando o campo tem restrição de tamanho. O teclado continuará aceitando entrada além do limite esperado.'
