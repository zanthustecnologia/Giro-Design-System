# Virtual Keyboard

O Virtual Keyboard é um teclado on-screen para ambientes onde o teclado físico está indisponível ou não é desejável — como totens, terminais e caixas de pagamento. Ele se integra a campos de texto controlados e suporta três layouts: padrão (QWERTY), numérico e de telefone.

## Importação

```js
import { VirtualKeyboard } from '@giro-ds/react';
```

## Uso

<UsageGuidelines
  guidelines={[
    <>
      Sempre vincule o teclado a um campo de texto via <code>value</code> e <code>onChange</code>. O teclado é um componente controlado e não gerencia o estado do input por conta própria.
    </>,
    <>
      Use o layout <strong>numeric</strong> para entradas que aceitam somente dígitos, como PINs, senhas numéricas e códigos. Ele oferece uma interface mais simples e focada.
    </>,
    <>
      Use o layout <strong>phone</strong> para discagem de números telefônicos. Ele inclui os caracteres <code>*</code> e <code>#</code> presentes em teclados de telefonia.
    </>,
    <>
      Combine o <code>maxLength</code> com o campo de texto para garantir consistência entre o limite visual do input e o limite aplicado pelo teclado.
    </>,
    <>
      Use o estado <strong>disabled</strong> quando o contexto não permitir entrada de dados. Tanto o campo quanto o teclado devem ser desabilitados juntos para evitar inconsistências.
    </>,
    <>
      No modo <strong>native</strong>, passe um <code>ref</code> do campo de texto para a prop <code>targetRef</code>. O teclado aparecerá ao focar no campo e sumirá ao perder o foco.
    </>,
  ]}

## Modos

O VirtualKeyboard possui dois modos de exibição, configurados pela prop `mode`.

### Fixed

O teclado fica sempre visível na tela com um **TextField próprio** acima. O campo é somente leitura — toda a entrada vem pelas teclas do teclado. Ideal para totens, painéis e interfaces sem teclado físico onde a digitação é o fluxo principal.

Use `textFieldLabel` e `textFieldPlaceholder` para personalizar o campo interno.

<Canvas of={VirtualKeyboardStories.ModoFixed} />

### Native

O teclado age como um teclado nativo: aparece quando o campo referenciado por `targetRef` recebe foco e some ao perder o foco (com um debounce de 150ms para não fechar antes do clique na tecla ser processado). Se `targetRef` não for fornecido, o teclado permanece sempre visível.

## Variações

### Numérico

Indicado para entradas de PINs, senhas e códigos. Exibe apenas os dígitos de 0 a 9, além de backspace e enter.

<Canvas of={VirtualKeyboardStories.Numerico} />

### Telefone

Exibe o layout de discagem telefônica, com suporte a <code>*</code> e <code>#</code>.

<Canvas of={VirtualKeyboardStories.Telefone} />

### Desabilitado

O teclado bloqueado impede qualquer interação. Use junto com o campo de texto desabilitado.

<Canvas of={VirtualKeyboardStories.Disabled} />

### Com limite de caracteres

Use a prop <code>maxLength</code> para restringir o número de caracteres aceitos pelo teclado.
