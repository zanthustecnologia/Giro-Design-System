# Select

O Select é um campo de seleção que abre uma lista de opções ao ser clicado. O usuário escolhe uma ou mais opções e a lista fecha automaticamente. Suporta busca interna, ícones, subtítulos e agrupamento de itens em categorias expansíveis.

<Canvas of={SelectStories.Default} />

## Importação

```js
import { Select } from '@giro-ds/react';
```

## Uso

<UsageGuidelines
  guidelines={[
    <>
      Use o Select quando o usuário precisar escolher uma opção de uma lista. Para listas curtas (até 4 itens), considere usar <a href="?path=/docs/components-radio--docs">Radio buttons</a>, que mantêm todas as opções visíveis.
    </>,
    <>
      Sempre defina um rótulo descritivo para o campo. Campos sem rótulo são inacessíveis e dificultam o preenchimento de formulários.
    </>,
    <>
      Use o texto de orientação (placeholder) para indicar ao usuário o que ele deve selecionar, como "Selecione um estado" ou "Escolha uma categoria".
    </>,
    <>
      Ative a busca interna quando a lista tiver muitos itens. Isso evita que o usuário precise rolar por dezenas de opções para encontrar o que precisa.
    </>,
    <>
      Use a variante com múltipla seleção quando o usuário puder escolher mais de uma opção ao mesmo tempo. Para seleção única, use a variante padrão.
    </>,
    <>
      Use o estado desabilitado quando o campo não está disponível no momento, como quando depende de uma seleção anterior em outro campo.
    </>,
  ]}
/>

## Variações

### Com busca

Ative a busca interna para permitir que o usuário filtre as opções digitando. Recomendado para listas com mais de 8 itens.

<Canvas of={SelectStories.WithSearch} />

### Com ícones e subtítulo

Itens podem exibir um ícone e um subtítulo para complementar a informação principal.

<Canvas of={SelectStories.WithIcon} />

### Múltipla seleção

Use esta variante quando o usuário puder selecionar mais de uma opção ao mesmo tempo.

<Canvas of={SelectStories.Checkbox} />

### Com itens agrupados

Itens podem ser organizados em categorias expansíveis para facilitar a navegação em listas longas.

<Canvas of={SelectStories.Children} />

### Obrigatório

Quando o campo é obrigatório, uma mensagem de erro é exibida ao tentar avançar sem selecionar uma opção.

<Canvas of={SelectStories.Required} />

### Desabilitado

Use o estado desabilitado quando a seleção não está disponível no momento.

<Canvas of={SelectStories.Disabled} />

## O que fazer e não fazer

<ComponentRules
  rules={[
    {
      positive: {
        component: (
          <div style={{ maxWidth: 300 }}>
            <Select
              label="Estado"
              placeholder="Selecione um estado"
              items={[
                { value: 'sp', text: 'São Paulo' },
                { value: 'rj', text: 'Rio de Janeiro' },
                { value: 'mg', text: 'Minas Gerais' },
              ]}
            />
          </div>
        ),
        description: "Use um rótulo e um texto de orientação que indiquem claramente o que deve ser selecionado."
      },
      negative: {
        component: (
          <div style={{ maxWidth: 300 }}>
            <Select
              placeholder="Selecione"
              items={[

                { value: 'mg', text: 'Minas Gerais' },
              ]}
            />
          </div>
        ),
