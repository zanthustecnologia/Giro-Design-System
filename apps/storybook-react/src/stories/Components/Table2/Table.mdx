# Table2

O Table2 é a nova implementação da tabela, construída com [TanStack Table](https://tanstack.com/table/latest). Oferece uma API declarativa baseada em `createColumnHelper`, com suporte a tipagem genérica, renderização customizada por célula e extensibilidade nativa da biblioteca.

<Canvas of={TableStories.Padrao} />

## Importação

```js
import { Table2 } from '@giro-ds/react';
import { createColumnHelper } from '@tanstack/react-table';
```

## Uso

<UsageGuidelines
  guidelines={[
    <>
      Use <code>createColumnHelper&lt;T&gt;()</code> para definir as colunas com tipagem automática. O helper garante autocompletar e segurança de tipos nas células.
    </>,
    <>
      Use <code>columnHelper.accessor('campo', {'{'} header, cell {'}'} )</code> para colunas que leem diretamente de uma propriedade do dado.
    </>,
    <>
      Use <code>columnHelper.display({'{'} id, cell {'}'} )</code> para colunas que não mapeiam uma propriedade do dado, como ações ou colunas compostas.
    </>,
    <>
      Acesse o dado original da linha com <code>row.original</code> dentro do render da célula para montar componentes como Chips e Menu.
    </>,
  ]}
/>
