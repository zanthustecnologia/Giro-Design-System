# TextField

TextField é um campo de entrada de texto que permite ao usuário digitar e editar informações. 
Pode ser configurado com rótulo, texto de ajuda, ícone, tooltip e validações, sendo adequado para formulários e coleta de dados.

<Canvas of={TextFieldStories.Default} />

## Importação

```js
import { TextField } from '@giro-ds/react';
```

## Uso

<UsageGuidelines
  guidelines={[
    <>
      Sempre forneça um <code>label</code> descritivo para identificar o propósito do campo.
    </>,
    <>
      Use <code>helperText</code> para orientar o usuário sobre o formato esperado da entrada.
    </>,
    <>
      Utilize <code>tooltip</code> e <code>tooltipText</code> para fornecer informações adicionais sem poluir a interface.
    </>,
    <>
      Use <code>icon</code> para reforçar visualmente o tipo de dado esperado (ex.: ícone de e-mail para campos de email).
    </>,
    <>
      Para campos obrigatórios, utilize a prop <code>required</code> em conjunto com uma mensagem de erro clara via <code>errorMessage</code>.
    </>,
  ]}
/>

## O que fazer e não fazer

<ComponentRules
  rules={[
    {
      negative: {
        component: <TextField label="Campo" placeholder="..." />,
        description: "Evite usar placeholders genéricos sem label. O placeholder desaparece ao digitar e não substitui o rótulo."
      },
      positive: {
        component: <TextField label="Nome completo" placeholder="Ex.: João Silva" />,
        description: "Use label descritivo e placeholder com exemplo concreto para guiar o usuário."
      }
    },
    {
      negative: {
        component: <TextField label="E-mail" helperText="Preencha corretamente." />,
        description: "Evite textos de ajuda vagos que não orientam o usuário sobre o formato esperado."
      },
      positive: {
        component: <TextField label="E-mail" icon={<Mail16Regular />} helperText="Ex.: nome@empresa.com.br" />,
        description: "Use helperText com exemplos claros e ícone para reforçar o tipo de dado esperado."
      }
    },
    {
      negative: {
        component: <TextField label="Telefone" required />,
        description: "Não deixe campos obrigatórios sem mensagem de erro orientativa para o usuário."
      },
      positive: {
        component: <TextField label="Telefone" required errorMessage="O telefone é obrigatório" helperText="Ex.: (11) 90000-0000" />,
        description: "Combine required com errorMessage descritiva e helperText com exemplo de formato."
      }
    },
  ]}
/>
