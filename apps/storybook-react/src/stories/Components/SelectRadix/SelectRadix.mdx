# Select

O componente Select permite que usuários escolham uma ou múltiplas opções de uma lista. 
Ele oferece três variantes (texto simples, com ícone e multi-seleção com checkbox), suporta busca e carregamento dinâmico de dados.

<Canvas of={SelectRadixStories.Default} />

## Importação

```js
import { SelectRadix } from '@giro-ds/react';
```

<Controls />

## Uso

<UsageGuidelines
  guidelines={[
    <>
      Use Select quando houver 5 ou mais opções disponíveis. Para menos opções, considere usar Radio ou Checkbox.
    </>,
    <>
      Sempre forneça um <code>label</code> claro que descreva o que está sendo selecionado.
    </>,
    <>
      Use <code>placeholder</code> para indicar uma ação (ex: "Selecione um framework") ou exemplo do tipo de conteúdo esperado.
    </>,
    <>
      Para campos obrigatórios, use a propriedade <code>required</code> que exibirá o asterisco vermelho ao lado do label.
    </>,
    <>
      Use <code>helperText</code> para fornecer contexto adicional sobre o campo ou instruções de preenchimento.
    </>,
    <>
      Use <code>errorMessage</code> para exibir mensagens de validação específicas quando o campo estiver inválido.
    </>,
    <>
      Para listas longas (mais de 20 itens), habilite a funcionalidade de busca com <code>search={'{'}true{'}'}</code>.
    </>,
    <>
      Use a variante <code>checkbox</code> quando o usuário precisar selecionar múltiplos itens.
    </>,
  ]}
/>
