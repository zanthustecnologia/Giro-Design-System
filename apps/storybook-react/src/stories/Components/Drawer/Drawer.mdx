# Drawer

O Drawer é um painel lateral deslizante que emerge da borda da tela sem remover o usuário do contexto atual.
É controlado externamente via `isOpen` e ideal para filtros, detalhes, formulários e notificações.

<Canvas of={DrawerStories.Default} />

## Importação

```js
import { Drawer } from '@giro-ds/react';
```

<Controls />

## Uso

<UsageGuidelines
  guidelines={[
    <>
      O Drawer é controlado externamente: use um estado para <code>isOpen</code> e passe <code>onClose</code> para fechar.
    </>,
    <>
      Utilize <code>title</code> sempre para identificar o contexto do painel ao usuário.
    </>,
    <>
      Use <code>headerContent</code> para adicionar ações contextuais ao cabeçalho, como botões de busca ou configurações.
    </>,
    <>
      Prefira larguras entre <code>360px</code> e <code>600px</code>. Para formulários complexos, use <code>customWidth</code> com o valor adequado.
    </>,
    <>
      Em fluxos obrigatórios, combine <code>closeOnOverlayClick={'{false}'}</code> e <code>closeOnEscape={'{false}'}</code> para evitar fechamento acidental.
    </>,
  ]}
/>
