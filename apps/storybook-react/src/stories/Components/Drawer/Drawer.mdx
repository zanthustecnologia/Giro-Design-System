# Drawer

O Drawer é um painel deslizante que aparece pela lateral direita da tela sobre um overlay semitransparente. É usado para exibir conteúdo secundário, formulários, filtros ou configurações sem remover o usuário do contexto principal da página. O estado de abertura é controlado externamente.

## Importação

```js
import { Drawer } from '@giro-ds/react';
```

## Uso

## Variações

### Largura customizada

Use `customWidth` para controlar a largura do painel. O valor padrão é `400px`. Em dispositivos móveis, o Drawer sempre ocupa 100% da tela independentemente dessa prop.

<img src={DrawerLarguraCustomizada} alt="Drawer com largura expandida mostrando mais conteudo" style={{ width: '100%', borderRadius: '8px', marginTop: '16px' }} />

### Sem fechamento por overlay

Com o fechamento por overlay e por Escape desativados, o usuário só pode fechar o Drawer pelos botões de ação disponíveis no conteúdo. Útil para formulários onde a saída inadvertida causaria perda de dados.
