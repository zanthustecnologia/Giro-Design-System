# Verification Code

O Verification Code é um campo de entrada para códigos de uso único (OTP), construído sobre o primitivo [Radix UI](https://www.radix-ui.com/primitives/docs/components/one-time-password-field). Suporta navegação por teclado, colagem, autofill de gerenciadores de senhas e integração nativa com formulários HTML.
