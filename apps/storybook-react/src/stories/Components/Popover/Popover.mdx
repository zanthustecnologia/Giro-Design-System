# Popover

O Popover é um painel flutuante ancorado a um gatilho. Diferente do Tooltip, ele exibe conteúdo interativo: informações estruturadas, ações rápidas ou confirmações simples. É construído sobre o Radix UI Popover, garantindo comportamento acessível e controle de foco por padrão.

<Canvas of={PopoverStories.Default} />

## Importação

```js
import { Popover } from '@giro-ds/react';
```

## Uso

<UsageGuidelines
  guidelines={[
    <>
      O gatilho pode ser qualquer elemento: um botão, ícone ou link. O Popover se ancora automaticamente a ele.
    </>,
    <>
      O conteúdo interno é livre: use texto, ícones, ações ou dados complementares conforme a necessidade.
    </>,
    <>
      Você pode controlar de qual lado o painel abre em relação ao gatilho: acima, abaixo, à esquerda ou à direita. O padrão é abaixo, à esquerda, o componente se reposiciona automaticamente se não houver espaço suficiente na tela.
    </>,
        <>
      O Popover fecha automaticamente ao clicar fora do painel ou pressionar Escape. Não é necessário controlar o estado de abertura manualmente.
    </>,
    <>
      Mantenha o conteúdo breve e objetivo.
    </>,
  ]}
/>

## Variações

### Posicionamento

Use as opções de posicionamento para abrir o Popover acima, abaixo, à direita ou à esquerda do gatilho. O componente se reposiciona automaticamente se houver colisão com a borda da tela.

<Canvas of={PopoverStories.Posicionamento} />

### Com confirmação

O Popover pode conter ações simples como arquivamento ou exclusão, sem exigir um Dialog modal completo.
