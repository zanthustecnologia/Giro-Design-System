# Chips

Chips são elementos compactos e em destaque usados para representar atributos, categorias, status ou filtros associados a um conteúdo. Eles comunicam informação de forma concisa e visual, sem a necessidade de ações do usuário.

<Canvas of={ChipsStories.Default} />

## Importação

```js
import { Chips } from '@giro-ds/react';
```

## Uso

<UsageGuidelines
  guidelines={[
    <>
      Use Chips para representar atributos de um item, como categorias, tags, status ou filtros aplicados. Eles não são botões e não devem acionar ações primárias.
    </>,
    <>
      Escolha o <code>variant</code> de acordo com a semântica do conteúdo: <code>success</code> para estados ativos ou positivos, <code>alert</code> para situações que requerem atenção, <code>neutral</code> ou <code>brand</code> para classificações e etiquetas informativas.
    </>,
    <>
      Para cores fora dos presets semânticos, use as props <code>backgroundColor</code> e <code>foregroundColor</code> passando qualquer token CSS do sistema sem o prefixo <code>--</code>. Ex: <code>backgroundColor="color-brand-secondary-medium"</code>.
    </>,
    <>
      Use ícones à esquerda para reforçar visualmente a semântica do tipo. Use ícones à direita, como o de fechar, apenas quando o chip representar um filtro removível.
    </>,
    <>
      Mantenha o texto do chip curto, preferencialmente uma ou duas palavras. Chips longos perdem seu propósito de ser compacto e legível de relance.
    </>,
    <>
      Não use chips para substituir <a href="?path=/docs/components-button--docs">Button</a> em ações do usuário. Para filtros interativos com seleção, considere o componente <a href="?path=/docs/components-filter--docs">Filter</a>.
    </>,
  ]}
/>

### Interativo (com `onClick`)

Quando `onClick` é passado, o chip recebe automaticamente `role="button"` e `tabIndex={0}`, tornando-o acessível via teclado. No estado `disabled`, o `tabIndex` é removido.

## O que fazer e não fazer

<ComponentRules
  rules={[
    {
      negative: {
        component: <Chips variant="neutral">Clique aqui para filtrar por categoria de produto</Chips>,
        description: "Evite textos longos no chip. O componente é projetado para conteúdo conciso e de leitura imediata."
      },
      positive: {
        component: <Chips variant="neutral" leftIcon={<Tag16Regular />}>Eletrônicos</Chips>,
        description: "Use textos curtos, preferencialmente uma ou duas palavras que identifiquem o atributo de forma direta."
      }
    },
    {
      negative: {
        component: (
          <div style={{ display: 'flex', gap: '8px' }}>
            <Chips variant="success">Aprovado</Chips>
            <Chips variant="alert">Aprovado</Chips>
          </div>
        ),
        description: "Evite usar variants que contradizem o conteúdo. Um chip de 'Aprovado' com variant alert cria conflito semântico."
      },
      positive: {
        component: (
          <div style={{ display: 'flex', gap: '8px' }}>
            <Chips variant="success" leftIcon={<CheckmarkCircle16Regular />}>Aprovado</Chips>
            <Chips variant="alert" leftIcon={<Warning16Regular />}>Pendente</Chips>
          </div>
        ),
        description: "Alinhe sempre o variant e o ícone com o significado do conteúdo. Isso garante coerência semântica e visual."
      }
    },
    {
      negative: {
        component: <Chips variant="brand">Salvar alterações</Chips>,
        description: "Não use chips para representar ações que o usuário deve executar. Chips comunicam atributos, não ações."
      },
      positive: {
        component: (
          <div style={{ display: 'flex', gap: '8px' }}>
            <Chips variant="neutral">Rascunho</Chips>
            <Chips variant="success">Publicado</Chips>
          </div>
        ),
        description: "Use chips para indicar o estado atual de um item. Para ações, utilize o componente Button."
      }
    }
  ]}
/>
