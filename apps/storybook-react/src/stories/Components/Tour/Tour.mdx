# Tour

O Tour exibe um guia passo a passo interativo na página, destacando elementos e exibindo instruções ao usuário. É ideal para onboarding e apresentação de novas funcionalidades.

<Canvas of={TourStories.Default} />

## Importação

```js
import { Tour } from '@giro-ds/react';
```

## Uso

<UsageGuidelines
  guidelines={[
    <>
      Use o Tour para apresentar novas funcionalidades ou guiar usuários durante o onboarding. Evite usá-lo para substituir documentação permanente na interface.
    </>,
    <>
      Mantenha cada passo com texto curto e objetivo. O usuário deve conseguir absorver a informação rapidamente antes de avançar.
    </>,
    <>
      Forneça sempre os callbacks <code>onExit</code> e <code>onComplete</code> para atualizar o estado que controla <code>isOpen</code>, garantindo que o tour feche corretamente.
    </>,
    <>
      Prefira destacar elementos que realmente precisam de explicação. Tours longos ou com muitos passos tendem a ser ignorados pelo usuário.
    </>,
    <>
      Certifique-se de que os seletores passados em <code>element</code> existem no DOM antes de abrir o tour; caso contrário, o balão será renderizado sem âncora.
    </>,
  ]}
/>
