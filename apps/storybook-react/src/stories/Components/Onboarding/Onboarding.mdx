# Onboarding

O Onboarding suporta dois modos de exibição:

- **Tour** — guia passo a passo que destaca elementos sequencialmente
- **Hint** — marcadores fixos e clicáveis distribuídos pela página

<Canvas of={OnboardingStories.Default} />

## Importação

```js
import { Onboarding } from '@giro-ds/react';
```

### Modo Hint

Marcadores fixos clicáveis exibidos sobre elementos da página. Controlados pela prop `isOpen`.

<Canvas of={OnboardingStories.HintMode} />

```tsx
<Onboarding
  mode="hint"
  isOpen={showHints}
  hints={[
    { element: '#btn-salvar', hint: 'Salva todas as alterações.', hintPosition: 'top-middle' },
    { element: '#btn-exportar', hint: 'Exporta em CSV ou PDF.', hintPosition: 'top-middle' },
  ]}
/>
```

## Uso

<UsageGuidelines
  guidelines={[
    <>
      Use o modo <strong>tour</strong> para apresentar novas funcionalidades de forma sequencial. Use o modo <strong>hint</strong> quando o usuário precisar de referências persistentes e não sequenciais.
    </>,
    <>
      Mantenha cada passo ou hint com texto curto e objetivo. O usuário deve absorver a informação rapidamente.
    </>,
    <>
      No modo tour, forneça sempre os callbacks <code>onExit</code> e <code>onComplete</code> para atualizar o estado de <code>isOpen</code> e garantir que o guia feche corretamente.
    </>,
    <>
      No modo hint, use <code>isOpen</code> para controlar a visibilidade de todos os marcadores de uma vez. Combine com um botão de "Mostrar dicas" para dar controle ao usuário.
    </>,
    <>
      Certifique-se de que os seletores passados em <code>element</code> existem no DOM antes de ativar o onboarding.
    </>,
  ]}
/>
