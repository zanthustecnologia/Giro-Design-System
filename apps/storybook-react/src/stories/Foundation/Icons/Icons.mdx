# Icons

Os ícones são elementos visuais fundamentais que comunicam ações, conceitos e estados de forma clara e universal. No Giro, utilizamos o **Fluent System Icons** da Microsoft, uma biblioteca robusta e consistente que oferece milhares de ícones em dois estilos: Regular e Filled.

Cada ícone é projetado para manter clareza em diferentes tamanhos, garantindo legibilidade e reconhecimento imediato em qualquer contexto de uso.

## Por que Fluent Icons?

- **Consistência Visual**: Mantém um estilo coerente com proporções e pesos balanceados
- **Acessibilidade**: Projetados com contraste adequado e formas reconhecíveis
- **Variedade**: Mais de 3.000 ícones cobrindo diversos casos de uso
- **Dois Estilos**: Regular (outline) para estados normais, Filled para estados ativos ou destaque
- **Escalabilidade**: Funciona perfeitamente em tamanhos de 16px a 48px

## Uso

`@fluentui/react-icons` já é instalado automaticamente como dependência de `@giro-ds/react`. Não é necessário instalá-lo separadamente.

### Importação

```jsx
import { Add20Regular, Delete20Regular, Edit20Filled } from '@fluentui/react-icons';

function MyComponent() {
  return (
    <button>
      <Add20Regular />
      Adicionar
    </button>
  );
}
```

## Tamanhos

Os ícones do Fluent estão disponíveis em tamanhos padrão. Use o sufixo numérico para indicar o tamanho:

```jsx
import { 
  Add16Regular, 
  Add20Regular, 
  Add24Regular,
  Add28Regular,
  Add48Regular 
} from '@fluentui/react-icons';
```

## Estilos

### Regular (Outline)

Use para estados padrão, ações secundárias e contextos onde o ícone precisa ser discreto.

### Filled

Use para estados ativos, selecionados ou quando o ícone precisa de maior peso visual.

```jsx
import { Star20Regular, Star20Filled } from '@fluentui/react-icons';

// Estado não selecionado
<Star20Regular />

// Estado selecionado
<Star20Filled />
```

## Diretrizes de uso

### Tamanho e Contexto

- Use **16px** para textos, padrão em botões e controles
- Nunca use ícones menores que 16px para manter acessibilidade

### Cor

Os ícones devem herdar a cor do texto pai ou usar tokens de cor do design system para garantir consistência:

```jsx
// Herda cor do texto
<button style={{ color: 'var(--color-brand-primary-default)' }}>
  <Add20Regular />
  Adicionar
</button>

// Cor direta no ícone
<Add20Regular style={{ color: 'var(--color-feedback-success-default)' }} />
```

### Alinhamento

- Alinhe verticalmente com o texto adjacente
- Mantenha espaçamento de 8px entre ícone e texto
- Use `vertical-align: middle` ou flexbox para alinhamento preciso

### Acessibilidade

- Sempre forneça texto alternativo quando o ícone transmite informação
- Use `aria-label` ou `aria-labelledby` para ícones interativos
- Mantenha área de toque mínima de 44x44px para ícones clicáveis

```jsx
<button aria-label="Adicionar item">
  <Add20Regular />
</button>
```
