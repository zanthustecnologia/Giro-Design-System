# Colors

Nossas cores foram projetadas para reduzir atrito cognitivo, criar ritmo visual e manter a experiência consistente. Elas não existem apenas para adornar a interface, são parte essencial da comunicação, ajudando usuários a interpretar estados, perceber hierarquias e tomar decisões com rapidez.

Nosso sistema cromático combina clareza operacional, acessibilidade (WCAG 2.2 AA/AAA como referência) e coerência semântica, garantindo que cada cor cumpra uma função inequívoca.

## Brand colors

Estabelecem identidade e reconhecimento. Cores primárias e secundárias são usadas para ações, elementos-chave e presença institucional de cada marca.
