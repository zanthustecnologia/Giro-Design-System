# Typography

Nosso sistema tipográfico prioriza leitura imediata, contraste adequado e hierarquia clara, permitindo que o usuário entenda o que importa no ritmo certo, sem esforço.

A Figtree é a base dessa construção. Sua forma limpa, moderna e equilibrada oferece legibilidade em qualquer densidade de conteúdo, enquanto seus pesos variados trazem a flexibilidade necessária para criar ênfase, ritmo e personalidade onde a interface pede.

## Tokens de design

Há dois conjuntos principais de tokens: <code>$font-size</code> e <code>$font-weight</code>. Essa divisão não é apenas uma escolha organizacional, ela estabelece a base para um sistema tipográfico modular, flexível e escalável, que funciona de forma consistente.

### Pesos

Os tokens de font-weight controlam ênfase e hierarquia sem depender exclusivamente de cor ou tamanho. Cada peso é usado para direcionar o olhar e comunicar níveis de importância com precisão.
