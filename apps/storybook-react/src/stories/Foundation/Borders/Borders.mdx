# Borders

Os tokens de borda organizam dois aspectos essenciais da composição: forma e definição.

O <code>$border-radius</code> determina o nível de arredondamento dos componentes, criando uma linguagem visual que equilibra suavidade e precisão. Já o <code>$border-width</code> define a espessura das bordas, garantindo clareza, contraste e suporte aos diferentes estados de interação.

## Border width

Os tokens de <code>border-width</code> especificam a espessura das bordas aplicadas a elementos estruturais e interativos. Variando de linhas finas a traços mais marcados, eles ajudam a comunicar importância, reforçar estados como foco ou alerta e manter uma aparência consistente e acessível em toda a interface.
