# Spacing

Os tokens de espaçamento definem o respiro e a organização entre elementos, tanto dentro de componentes quanto na composição. Eles criam uma lógica previsível de proximidade e separação, facilitando a leitura, reduzindo ruído visual e fortalecendo a hierarquia.

Nossa escala de espaçamento oferece um padrão consistente que ajuda usuários a escanearem a interface com mais naturalidade, mantendo equilíbrio entre densidade e clareza. Ao aplicar esses valores de forma sistemática, garantimos interfaces harmoniosas, acessíveis e mais fáceis de navegar em qualquer contexto ou plataforma.
