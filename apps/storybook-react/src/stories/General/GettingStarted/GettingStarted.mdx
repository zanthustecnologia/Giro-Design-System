# Comece aqui

Bem-vindo ao Zanthus Design System! Este guia vai ajudá-lo a começar a usar nossos componentes e recursos de forma rápida e eficiente.

## Instalação

### Componentes React

Para instalar o pacote de componentes React em seu projeto:

```bash
# npm
npm install @giro-ds/react

# pnpm (recomendado)
pnpm add @giro-ds/react

# yarn
yarn add @giro-ds/react
```

### Design Tokens

Para usar os tokens de design (cores, tipografia, espaçamentos, bordas):

```bash
# npm
npm install @giro-ds/tokens

# pnpm (recomendado)
pnpm add @giro-ds/tokens

# yarn
yarn add @giro-ds/tokens
```

### Utilitários CSS

Para usar os utilitários de layout e espaçamento:

```bash
# npm
npm install @giro-ds/utilities

# pnpm (recomendado)
pnpm add @giro-ds/utilities

# yarn
yarn add @giro-ds/utilities
```

### Instalação completa

Para instalar todos os pacotes de uma vez:

```bash
# npm
npm install @giro-ds/react @giro-ds/tokens @giro-ds/utilities

# pnpm (recomendado)
pnpm add @giro-ds/react @giro-ds/tokens @giro-ds/utilities

# yarn
yarn add @giro-ds/react @giro-ds/tokens @giro-ds/utilities
```

## Configuração inicial

### 1. Importe os estilos globais

No arquivo principal da sua aplicação (geralmente `App.jsx`, `App.tsx` ou `main.jsx`), importe os tokens de design e estilos dos componentes:

```jsx
// Tokens de design (cores, espaçamentos, tipografia, bordas)
import '@giro-ds/tokens/build/css/tokens.css';

// Estilos dos componentes React
import '@giro-ds/react/dist/styles.css';

// (Opcional) Utilitários CSS para layout
import '@giro-ds/utilities/dist/ui.css';
```

### 2. Configure a fonte Figtree

Adicione a fonte Figtree no `<head>` do seu HTML (em `index.html` ou layout raiz):

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Figtree:ital,wght@0,300..900;1,300..900&display=swap" rel="stylesheet">
```

### 3. Importe os componentes

Você pode importar componentes individuais conforme necessário:

```jsx
import { Button, TextField, Avatar } from '@giro-ds/react';

function App() {
  return (
    <div>
      <Button variant="primary">Clique aqui</Button>
      <TextField label="Nome" placeholder="Digite seu nome" />
      <Avatar name="João Silva" />
    </div>
  );
}
```

## Estrutura do projeto

O Zanthus Design System é organizado em três pacotes principais:

### @giro-ds/tokens

Contém todos os design tokens (cores, tipografia, espaçamentos, bordas) em múltiplos formatos:
- **CSS Variables** (`build/css/tokens.css`): Para uso direto em CSS/SCSS
- **JavaScript/TypeScript** (`build/js/tokens.js`): Para uso em aplicações React
- **SCSS Variables** (`build/scss/tokens.scss`): Para projetos que usam SCSS

### @giro-ds/react

Biblioteca de componentes React prontos para uso:
- Componentes acessíveis (WCAG 2.1)
- TypeScript com tipos completos
- Totalmente customizáveis via props
- Documentação detalhada de cada componente
- Inclui estilos CSS em `dist/styles.css`

### @giro-ds/utilities

Utilitários CSS para layout e espaçamento:
- Grid system responsivo
- Flexbox helpers
- Spacing utilities
- Breakpoints padronizados
- Compilado em `dist/ui.css`

## Usando design tokens

### CSS Variables

Os tokens estão disponíveis como CSS custom properties:

```css
.meu-componente {
  color: var(--color-brand-primary-default);
  padding: var(--spacing-16);
  border-radius: var(--border-radius-8);
  font-family: var(--font-family-primary);
}
```

### SCSS Variables

Se você preferir SCSS, importe os tokens SCSS:

```scss
@import '@giro-ds/tokens/build/scss/tokens.scss';

.meu-componente {
  color: $color-brand-primary-default;
  padding: $spacing-16;
  border-radius: $border-radius-8;
}
```

### JavaScript/TypeScript

Para uso em styled-components, estilos inline ou temas dinâmicos:

```jsx
// Importação ESM (recomendado)
import tokens from '@giro-ds/tokens/build/js/tokens.js';

// Uso em styled-components
const MyComponent = styled.div`
  color: ${tokens.colorBrandPrimaryDefault};
  padding: ${tokens.spacing16};
  border-radius: ${tokens.borderRadius8};
`;

// Uso em estilos inline
const styles = {
  color: tokens.colorBrandPrimaryDefault,
  padding: tokens.spacing16,
};
```

## Tipografia

O Zanthus Design System usa a fonte **Figtree** como tipografia principal. Para garantir que a fonte seja carregada corretamente, adicione ao `<head>` do seu HTML (geralmente em `index.html`):

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Figtree:ital,wght@0,300..900;1,300..900&display=swap" rel="stylesheet">
```

Ou importe via CSS:

```css
@import url('https://fonts.googleapis.com/css2?family=Figtree:ital,wght@0,300..900;1,300..900&display=swap');
```

## Exemplo completo

Aqui está um exemplo completo de configuração em uma aplicação React:

```jsx
// main.jsx ou App.jsx
import React from 'react';
import ReactDOM from 'react-dom/client';

// 1. Importar estilos do design system
import '@giro-ds/tokens/build/css/tokens.css';
import '@giro-ds/react/dist/styles.css';
import '@giro-ds/utilities/dist/ui.css'; // Opcional

// 2. Importar componentes
import { Button, TextField, Avatar, Container } from '@giro-ds/react';

function App() {
  return (
    <Container>
      <h1 style={{ 
        fontFamily: 'var(--font-family-primary)',
        color: 'var(--color-neutral-low-default)' 
      }}>
        Minha Aplicação
      </h1>
      
      <Avatar 
        name="Maria Silva" 
        size="large" 
      />
      
      <TextField 
        label="Email" 
        type="email"
        placeholder="seu@email.com"
      />
      
      <Button variant="primary">
        Entrar
      </Button>
    </Container>
  );
}

ReactDOM.createRoot(document.getElementById('root')).render(
  <React.StrictMode>
    <App />
  </React.StrictMode>
);
```

E no seu `index.html`:

```html
<!DOCTYPE html>
<html lang="pt-BR">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Minha Aplicação</title>
    
    <!-- Fonte Figtree -->
    <link rel="preconnect" href="https://fonts.googleapis.com">
    <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
    <link href="https://fonts.googleapis.com/css2?family=Figtree:ital,wght@0,300..900;1,300..900&display=swap" rel="stylesheet">
  </head>
  <body>
    <div id="root"></div>
    <script type="module" src="/src/main.jsx"></script>
  </body>
</html>
```

Se você está contribuindo para o design system:

```bash
# Instalar dependências
pnpm install

# Build de todos os pacotes
pnpm build

# Modo desenvolvimento (watch)
pnpm dev

# Rodar Storybook
pnpm storybook

# Build de um pacote específico
pnpm --filter @giro-ds/tokens build
pnpm --filter @giro-ds/react build
pnpm --filter @giro-ds/utilities build
```

Consulte [docs/instructions-pnpm.md](https://github.com/zanthus/design-system/blob/main/docs/instructions-pnpm.md) para mais comandos.
