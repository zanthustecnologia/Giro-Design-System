Toda decisão de espaçamento no Giro DS é um múltiplo de 4: 4, 8, 12, 16, 24, 32, 40, 48, 64, 80. Isso cria ritmo visual consistente e elimina o problema de três desenvolvedores diferentes escolhendo valores diferentes para o mesmo contexto.
